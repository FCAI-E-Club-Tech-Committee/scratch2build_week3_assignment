# FCAI Activity Portal — Interactive Event Filter App

A client-side event creation and dynamic filtering module built with semantic HTML5, Vanilla CSS, and ES6+ Vanilla JavaScript.

## Features
- **Interactive Form & Validation:** Validates event title length (minimum 3 trimmed characters) and category selection with inline error feedback.
- **Dynamic DOM Manipulation:** Adds styled event cards with category badges (`Tech`, `Workshop`, `Social`) and removes cards via Event Delegation.
- **Real-Time Dual Filtering:** Combines live keyword search (`input` event) and category filtering (`change` event) simultaneously.
- **Live Counter & Empty State:** Automatically updates the visible event count and displays a fallback state when no events match.

## Setup & Usage
1. Clone the repository.
2. Open `index.html` directly in any modern web browser.
